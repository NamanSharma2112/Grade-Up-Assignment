This repository contains the complete assessment submission for **TECH1400 Database Design and Management (Assessment 2)**. ### Summary of Normalisation Stages
- **UNF (Unnormalised Form):** Monolithic clinic record with 12 attributes including a nested repeating group `{TreatmentCode, TreatmentDescription, TreatmentFee}`.
- **1NF (First Normal Form):** Repeating groups flattened; atomic values enforced; Composite Primary Key established: `(AppointmentID, TreatmentCode)`. Exposes partial dependencies (violating 2NF) and transitive dependencies (violating 3NF).
- **2NF (Second Normal Form):** Partial dependencies removed by decomposing into `APPOINTMENT`, `TREATMENT`, and associative bridge table `APPOINTMENT_TREATMENT`.
- **3NF (Third Normal Form):** Transitive dependencies removed by isolating non-key determinants into independent master tables: `PATIENT`, `DOCTOR`, and `DEPARTMENT`.
